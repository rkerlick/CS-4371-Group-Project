## How to use this log

AI use in this project is required, not banned. Every AI output the team relies on - a claim repeated, a citation included, code committed, or an idea adopted - should appear here as one row, whether or not it turned out to be correct. Throwaway drafts or outputs that were discarded without being used do not need to be logged.

Keep one log for the team in the root of the GitHub repository and update it as the project progresses rather than rebuilding it at the end.
